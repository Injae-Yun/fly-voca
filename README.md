# fly-voca

FlyWire FAFB v783 · BANC v888 커넥톰 위에서 초파리의 **내부 상태(감정)를
읽는** 시도, 그리고 그 상태가 왜 시뮬레이션 안에 생기지 않는지를 잰 기록.

`fly_voca` 우산 아래의 한 시스템이다. 시뮬레이터(`flyvoca.sim`, GPU LIF)와
그래프(`flyvoca.graph`)는 공유 모듈 `core`에 있고, 데이터는 `data/`에서
공유한다. 둘 다 이 리포에 들어오지 않는다.

## 무엇이 있나

```
voca/state.py       8차원 상태 축 — 배고픔·갈증·각성·구애·방어·미각·조향 (검증된 세포유형)
voca/peptide.py     펩타이드 느린 층 — 농도·수용체 부호·휴지전위 이동
voca/expression.py  수용체 발현 (중심복합체 EASI-FISH; 미측정과 미발현을 구분)
voca/monoamine.py   모노아민 엣지 느린 층 — 시행별 농도, 포화, 상한
voca/reference.py   Shiu et al. 2024 기준 모델과의 대조
scripts/            번호순 실험. 10~15 보정 · 20~22 휴지 상태 · 30~32 펩타이드 ·
                    54~55 하강뉴런 스캔 · 80~99 BANC와 지속 · A0~A10 고리·느린 층·민감도
```

## 지금까지의 결론 (문서 15~19)

상태 세포는 자극이 끝나면 250 ms 안에 기저로 돌아간다. 이것은 결함이
아니라 관측과 일치한다 — pC1d·aIPg는 실제 파리에서도 지속하지 않는다
(Chiu et al. 2024). 지속을 나르는 것은 그 하류이고, 이 모델 부류(균일 LIF +
단일 부호·gain·tau 느린 층)로는 세 방향(고리 이득, 뇌 전체 스캔, 몸 고리)에서
같은 수치로 그것이 나오지 않는다. 고유값 기준으로 고리는 자립에 2배
모자라고 pC1d/e의 입력 민감도 4배면 넘지만, 측정된 형태(표면적)는 그
반대 방향을 준다. 남은 것은 세포별 내재 흥분성이며 이는 기록에서만 온다.

실험 노트는 `core/docs/` (로컬 공유)에 있다.

## 설치

`fly_voca` 루트의 공유 `.venv`를 쓴다.

```bash
D:/Code/fly_voca/.venv/Scripts/python.exe -m pip install -e D:/Code/fly_voca/core -e .
```

수칙: 조건 간 시드 짝맞춤, 효과 크기는 Cohen's d, sham은 다른 시드의 기저,
숫자는 있는 그대로. 반증도 결과다. 통과시키려고 파라미터를 조정하지 않는다.
