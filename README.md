# bodysnatch

FlyWire FAFB v783 커넥톰 위에서 **환경 인식 · 감정 해독 · 동작 학습**을 세우고,
그 폐루프에 끼어들어 행동을 탈취한다.

## 왜 가능한가

초파리 중심복합체의 조향 회로가 세포유형 수준까지 풀려 있고, v783 데이터에
전부 들어있다 (`core/docs/01-validation.md` 검증 참조).

```
EPG 51    나침반 — 현재 머리 방향
FC2 85    목표 — 가고 싶은 방향
PFL3 24   비교기 — 나침반과 목표의 차이를 좌/우로 변환
DNa02 2   조향 명령 (좌 1 · 우 1)
```

검증에서 PFL3 → DNa02가 **완전 교차**(동측 0, 반대측 279/266)로 확인됐다.
목표 벡터가 뇌 안에 명시적 뉴런 집단으로 존재한다는 뜻이고, 그것이 개입 지점이다.

## 탈취 등급

```
Lv1  감각 위조      가짜 설탕 · 가짜 천적            뇌가 속는다
Lv2  욕구 변조      배고픔/각성 뉴런 클램프          원하는 것이 바뀐다
Lv3  목표 덮어쓰기  FC2 기둥에 목표 주입        ★ 제 의지로 내 목적지로 간다
Lv4  세계 위조      EPG 나침반 · 상행뉴런에 주입 ★ 뇌는 멀쩡, 세계 모델만 조작
Lv5  직접 구동      DNa02 강제 발화                 뇌를 우회 — 그냥 꼭두각시
```

Lv3·Lv4가 본체다. Lv5는 뇌를 건너뛰므로 흥미가 없다.

FC2의 목표 신호는 좌우가 아니라 **기둥(column) 각도**로 부호화된다 —
검증에서 FC2 → PFL3이 네 조합 모두 고르게 나온 이유. 따라서 Lv3 주입은
side가 아니라 column 단위로 한다 (`column_assignment.csv`).

## 감정 = 8차원 내부 상태 벡터

느린 레이어(DA/5-HT/OA + 펩타이드)에서 읽는다. 내분비 80개가 펩타이드명으로
타이핑돼 있어 **송신자** 측은 확보됐다. **수용체** 측은 전사체 데이터가 필요하다.

| 축 | 읽는 세포 |
|---|---|
| 배고픔 | m_NSC_DILP 18 · m_NSC_DH44 · SEZ_NSC_Hugin · l_NSC_DH31 |
| 갈증 | ISN |
| 각성/수면 | ER5 · FB6/FB7(dFB) · s-LNv · l-LNv · LNd · DN1 |
| 구애 | pC1a–e (FAFB는 암컷 — P1/pIP10 없음) |
| 방어 | LC4 · LPLC2 → DNp01 |
